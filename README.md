# RSS Feed for Mac

日別にニュースを読めるRSSリーダーです。Appleシリコン（M1以降）搭載のMac向けに配布しています。

[配布ZIPをダウンロード（約13.5MB）](https://github.com/MasterReek/rss-feed-downloads/releases/download/v2026.11.13/RSS-Feed-AppleSilicon-20261113.zip)

[リリース一覧](https://github.com/MasterReek/rss-feed-downloads/releases)

## 使い始めるまで

1. 上のリンクからZIPをダウンロードし、ダブルクリックで展開します。
2. 「RSS Feed.app」を「アプリケーション」フォルダへコピーします。
3. 「RSS Feed」を開き、「全RSSを更新」を押します。

Pythonなどの追加インストールは不要です。ニュース・本文・画像の取得にはインターネット接続が必要です。
詳しい使い方はZIP内の `Readme.txt` にあります。

## 初回に開けない場合

Appleの公証を行っていない個人配布版です。信頼する配布者から受け取ったものであることを確認してください。
一度起動を試みた後、「システム設定」→「プライバシーとセキュリティ」でRSS Feedの「このまま開く」を選択します。
[Appleの案内](https://support.apple.com/ja-jp/102445)

## データについて

既読履歴・保存記事・配布者のNGワード設定は含まれていません。
取得した記事・設定は、利用するMacの `~/Library/Application Support/RSS Feed` に保存されます。

このリポジトリはアプリの配布と使い方の案内専用です。
